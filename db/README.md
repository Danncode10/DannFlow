# Database Schema

This folder is the TypeScript-first database authoring layer.

```text
db/schema/*.ts     Drizzle table definitions
db/migrations/*    SQL generated by pnpm db:generate
db/migrate.ts      Applies generated SQL to Supabase using DATABASE_URL
```

Supabase still provides the hosted Postgres database, Auth, Storage, and RLS. The app's services still use `supabase-js`; Drizzle is used here for schema authoring and migrations.

After applying migrations, refresh `src/types/supabase.ts` so app code stays aligned with the live database.
